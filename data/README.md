# Data folder

Use only synthetic demonstration data in this repository.

Planned sample CSV columns:
- `date`
- `demo_region` (generic scenario label, not a sensitive real location)
- `supply_category`
- `daily_demand`
- `available_stock`
- `replenishment_lead_days`
- `incoming_quantity`
- `scenario_id`

Person 1 can add a small generated CSV under `data/sample/`. Do not commit private, personal, operational, or sensitive records.
