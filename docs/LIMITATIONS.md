# Limitations and Responsible Use

- This is a hackathon proof of concept, not a deployed logistics system.
- All supply/inventory demonstration data must be synthetic.
- Public web pages may be stale, incomplete, inaccurate, or unavailable.
- Retrieval time is not the same as source publication time.
- `needs_review` means evidence is available but a person must review it.
- A source URL or excerpt does not independently prove the source's claim.
- Search results can be irrelevant; relevance mapping must be explicit.
- Any initial risk score is a heuristic, not a calibrated probability.
- Do not store sensitive military locations, tactical routes, unit movements, deployment schedules, or other operationally sensitive information.
- No autonomous dispatch, purchasing, or irreversible actions are in scope.
- Do not claim measured accuracy, cost savings, or delay reduction without documented evaluation.
